164枚合計：完成版PNG 414.7 MiB → 通常表示 32.8 MiB（92.1％削減）、一覧用 7.2 MiB。PNGは削除していないため、保管リポジトリ全体の容量削減ではなく表示・配布時の軽量化です。

WebPは通常表示900px・品質82、一覧360px・品質78。PNGからそれぞれ直接変換し、圧縮画像の再圧縮を避けています。小さい一覧では絵柄を確認し、効果文は通常表示で確認してください。

本番外の保管専用ブランチです。画像制作とゲーム効果の実装・本番反映は別です。
