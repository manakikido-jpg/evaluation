# 神符合戦の完成画像100枚

画像制作の進捗は **100／237枚（42.2％）**。2026年10月18日にクラウドの制作成果を保存しました。

## 見る・保存する

- [原画PNGのフォルダ](originals/)で100枚を見られます。下のカード名からも開けます。
- 1枚ずつ保存する場合は画像を開き、GitHubの「Download raw file」を使います。
- まとめて保存する場合は、このブランチのリポジトリ画面で「Code → Download ZIP」を使い、展開後の `assets/shinpu-cards/originals/` を開いてください。リポジトリ全体を含むため容量は約255MB以上になります。
- [manifest.json](manifest.json) にカード名、数値、ファイルサイズ、SHA256を記録しています。

## 制作とゲーム実装の区別

このフォルダは制作画像の保管用です。ゲームの表示画像・カードデータへの自動追加は行いません。既存のイラスト単体と、文字入り完成見本の両方を含みます。画像の効果文は制作案であり、全効果が実装済みという意味ではありません。通常攻撃と＋付き追加攻撃の最新ルールは [決定事項](../../docs/user-decisions.md) を参照してください。
