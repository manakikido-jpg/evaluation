# 神符合戦：カード化済み100枚

**完成カード100／237枚（42.2％）**。2026年10月18日、保存済み100点のうち枠なしだった31点をカード化しました。新しい素材は増やしていません。

## 保存する

- [完成カード100枚のフォルダ](cards/)から、名前・数値・効果入りのPNGを取得できます。各画像の「Download raw file」で個別に保存できます。
- ブランチの「Code → Download ZIP」ではリポジトリ全体を取得します。画像の比較用原画も含むため、完成カードだけより容量が大きくなります。
- [比較用の修正前原画](originals/)はそのまま保持しています。こちらには枠なしのイラストが含まれるので、カードの取得には cards/ を使ってください。
- [manifest.json](manifest.json) に修正前原画と完成カード双方のサイズ・SHA256、[layout-progress.json](layout-progress.json) にカード化の進捗を記録しています。

## 表示とゲーム実装

採用済みの濃紺・銀枠にそろえました。武器と奇跡は攻撃、防具は防御、道具はHP・MP回復量を表示。紫電の短刀には＋3を表示しています。これらは制作見本で、効果のゲーム実装や本番への表示反映とは別です。画像は保管専用ブランチに保存し、本番へ合流しません。
