# 神殿スロットの別生成素材

ゲーム用ファイルは `src/web/public/gaisen-media/`。画像はWebP（1600px/800px）、効果音13種はステレオMP3（44.1kHz/128kbps）。実機の映像・録音・音楽を流用していません。

## 画像

画像生成ツールで2場面を独立生成しました。神殿建築は架空のものです。

- night: 青い夜明け前の大理石神殿、青紫の空、遠景の山と霧、桜、濡れた黒い石床と温かな灯の反射。正面対称構図、中央は数字を置ける余白、下部は暗め。物理ベースの映画的な石材・金属表現。文字・UI・人物・実在する機種の意匠は含めない。
- award: 大理石と古銅の巨大な門、金色の光を放つ扉、黒い石床の反射、金粉と桜。神を人物で描かず光と建築で表す。金と黒を基調にし、題字はHTMLで重ねる。文字・UI・人物・実在する機種の意匠は含めない。

生成元PNGはクラウドの `/workspace/generated_images/exec-1b9180cf-ac57-40b8-8d34-455b120eb055.png` と `/workspace/generated_images/exec-d3610fb2-db60-477d-a3b9-b8c9284e7ef5.png` に維持。これらの原画はGitには含めず、ゲーム用WebPを保存しています。別環境でPNGが存在するとは扱いません。

## 音源

この環境に音源生成AIサービスは接続されていません。音は `build_audio.py` により別ファイルとして制作した**物理モデルによる合成音**です。実機の録音や生演奏と呼びません。

機械音は衝撃・ばね・ラッチと金属の非整数倍モード、当選音は鐘の倍音・低い胴鳴り・左右で時差のある初期反射を重ねます。乱数seedを固定し、前後のフェードとピークの余裕を付けています。レバー、左右中の停止、払出、リプレイ、区間、時間停止、EX、GG、SGG、上乗せ、GODを分離しています。

再生成: `python3 assets/gaisen-media/build_audio.py`（Python 3、numpy、scipy、ffmpegが必要。ゲームの実行依存ではありません）。MP3エンコーダーのバージョンによってバイト列は変わり得ます。保存したファイルのサイズ・SHA256・音声形式は `manifest.json` で照合します。

音OFFで音源を取得せず、ON操作後に取得・復号して再利用。遅れてロードされた操作音は180msで打ち切り、ミュート・非表示・スキップ後に鳴らしません。音源の失敗でゲーム操作は失敗させません。実端末のスピーカーでの音質は別途確認が必要です。
