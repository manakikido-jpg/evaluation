# 金細工の実績バッジ

採用済みの桜3種と三日月/狐面/鳳凰/龍/鳥居/扇の見本をもとに、個別の透過PNGとして画像生成で制作しました。元の見本シートを背景ごと切り抜いた画像ではありません。

実績との対応はsrc/services/visitBadgeArt.ts、条件はvisitProfile.tsを正とします。sakura-ruby.pngは予備の中位桜で、実績や課金条件はまだ設定していません。

実績の8種類をWebの選択画面とカード描画で共用します。カード上は透過余白込み80px、Webでは56pxで表示。外部の画像サービスへ接続せずに描画できます。未獲得の絵を見本で見ても、実績を獲得したことにはなりません。

原画像を保管し、共通サービスが初回だけ256pxの配信画像へ描画してメモリに保持します。Webへ数MBの原画像は送らず、カードにも同じ軽い画像を埋め込みます。
