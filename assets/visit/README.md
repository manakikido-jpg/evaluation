# 参拝プロフィールの画像素材

咲楽ノ宮のプロフィール用に、画像生成ツールで新規制作した和風ファンタジー素材です。
参考画像のキャラクター・ロゴ・画面の切り抜きは使用していません。

- background-*.jpg：5種類の背景。1080×640、文字やフレームを含まないイラスト。
- frame-*.png：4種類の細い光の透過フレーム。1080×640、中央は透明。
- 細縁（plain）はカード生成側の金属調の線です。
- 文字・顔写真・数値・勲章・公開設定は素材へ焼き込まず、visitCard.tsが合成します。
- 背景とフレームはそれぞれ独立して変更できます。カード生成は外部画像サービスを呼びません。

素材はassets/fontsと同じくDockerの最終イメージへCOPYされます。
ブラウザへ素材のURLを渡さず、PNGとして合成したカードだけを返します。

最終採用は背景を主役にするシンプル版です。枠は青紫・桜色・金色・翡翠色、小さなバッジとコンパクトな文字を共通配置します。

運営専用「紅眼の金紋」：background-staff-crimson.png / frame-staff-crimson.png。
ユーザー提供の参考画像から、採用済みの背景と透過フレームを画像生成で制作。
上記の一般用5背景/4フレームとは別で、既存の宮司/神職ロールの対象者だけに合成する。
文字・実データは焼き込まず描画側で付ける。一般用カタログには登録しない。

運営専用「青夜の花灯り」：background-staff-blue-lantern.png / frame-staff-blue-lantern.png。
ユーザー提供の参考画像から生成し、中央の袖が透けて見える描写を修正した背景と青銀の透過フレームを採用。背景と枠を別々に保持して描画時に重ねます。運営専用の選択項目で赤金と切り替えます。

一般用「銀月の妖影」：background-silver-shadow.png / frame-shadow-silver.png。
ユーザー参考画像の顔立ちに寄せて修正した白黒の背景と、黒銀の桜/月/組紐の透過フレーム。無料の一般カタログへ追加。人物を覆わない左側の文字配置を使用し、運営の専用画像とは別の素材として扱います。

運営用「紫苑の金桜」：background-staff-purple-gold.png。
ユーザー提供の参考画像から生成した紫髪と金彩の着物の背景。運営の選択肢として登録し、frame-gold.pngと合成します。人物を右、記録とバッジを左へ配置します。
