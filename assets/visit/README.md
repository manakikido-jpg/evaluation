# 参拝プロフィールの画像素材

咲楽ノ宮のプロフィール用に、画像生成ツールで新規制作した和風ファンタジー素材です。
参考画像のキャラクター・ロゴ・画面の切り抜きは使用していません。

- background-*.jpg：5種類の背景。1080×640、文字やフレームを含まないイラスト。
- frame-*.png：4種類の透過フレーム。1080×640、中央は透明。
- 細縁（plain）はカード生成側の金属調の線です。
- 文字・顔写真・数値・勲章・公開設定は素材へ焼き込まず、visitCard.tsが合成します。
- 背景とフレームはそれぞれ独立して変更できます。カード生成は外部画像サービスを呼びません。

素材はassets/fontsと同じくDockerの最終イメージへCOPYされます。
ブラウザへ素材のURLを渡さず、PNGとして合成したカードだけを返します。
