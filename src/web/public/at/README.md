# 🦊 AT 機「鬼斬り白狐」の絵を置くフォルダ

ここに、下の **名前どおりのファイル名** で絵を置くと、台に出ます（自動更新のあと数分で）。

- 形式: `.png`・`.webp`・`.jpg`・`.gif`（同じ名前が 2 つあれば webp → png → jpg の順）
- ファイル名は **小文字の英数字とハイフン** だけ（例: `bg-normal.png`）。名前がちがうと読まれません
- キャラ・ロゴ・リールの絵柄・役物は、背景が透明な PNG か WebP に
- 1 枚はなるべく 2MB くらいまで（WebP にすると小さくなります）
- 社務所Web「🎰 カジノ」の絵の欄で入れた絵があれば、そちらが先に出ます（そちらを「消す」と、ここの絵に戻ります）

## 置き方（GitHub のサイトで）

1. このフォルダを開いた画面の右上「Add file」→「Upload files」
2. 絵のファイルをまとめてドラッグして入れる
3. いちばん下の「Commit changes」を押す
