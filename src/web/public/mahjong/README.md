# 🀄 麻雀の牌の絵

ここに画像を置くと、雀荘の牌がその絵になります（ない牌は、いままでどおり字で描きます）。

- 形式: `webp`・`png`・`jpg`・`svg`（同じ名前なら webp → png → jpg → svg の順に使う）
- 大きさ: 縦長 3:4（例: 300×400 px）。背景は透明か、牌の形いっぱいに
- 名前（全部で 38 枚）:
  - 萬子 `m1`〜`m9`・筒子 `p1`〜`p9`・索子 `s1`〜`s9`
  - 字牌 `ton`（東）・`nan`（南）・`sha`（西）・`pei`（北）・`haku`（白）・`hatsu`（發）・`chun`（中）
  - 赤ドラ `m5r`・`p5r`・`s5r`（なければ、ふつうの 5 の絵に赤い印を付ける）
  - 裏 `back`
- 置いたら、サーバーを入れ直すと（VPS は自動更新で）使われます。
