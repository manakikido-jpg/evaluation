## 新しい作業を記録するときの書式

同時作業のメモを消さず、日付と作業名を付けて追記するか、自分の作業の欄を更新します。終わった依頼も短く残します。

```text
日付・作業名：
依頼（ユーザーの言葉を短く）：
修正点・指摘・守ること：
開始時点と根拠（ファイル・PR・commit）：
状態（未着手／作業中／確認待ち／完了／停止）：
今回できたこと・保存先：
進捗（分母が確定している場合のみ枚数・％）：
次にすること・未決定事項・停止理由：
検証結果（未実行も明記）：
ブランチ・commit・PRと合流の確認時点：
```

## 新しいチャットへ渡す一文

「リポジトリのAGENTS.md、docs/user-decisions.md、docs/work-notes.mdを読み、最新のブランチ・PR・成果物を確認して、記録された続きから進めてください。」

このメモがあるブランチを取得してから読みます。チャットを変えただけで自動的に読み込まれる保証はありません。ローカル保存・commit・GitHubへのpushを区別し、未pushならそのことと保存先を伝えます。
