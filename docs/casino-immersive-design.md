# カジノの没入感デザイン

2026年10月28日、生成した3画面のイメージをユーザーが採用しました。夜桜の迎賓館（ルーレット）、花灯りの奥座敷（ブラックジャック）、狐面の勝負処（ハイロー）です。

## 今回の実装

社務所の「カジノの没入感テスト」 `/economy/casino-test` から、社務所の運営セッション/economyページ権限だけで試遊します。一般向けのゲーム画面は変えません。まず運営が見た目と使いやすさを確認する段階です。

- 絵素材は部屋とディーラーのみ。カード・数字・盤面・金額はHTMLで重ねます。画像内の誤った数字をゲームに流用しません。
- ルーレットは既存の37マス/数字順/境界の賭け/配当を共用し、盤を傾けて厚みと影を付けます。
- ブラックジャックは既存の山札/判定でヒット・スタンド・ダブル。ハイローは既存の確率・ドロー・連勝・受取を使います。連勝数に合わせて灯籠が灯ります。
- 回数と操作列のGETからサンプルを再現します。同じURLの再読込で結果が変わらず、実際の残高・卓・ゲーム・会員セッション・戦績は書きません。入力上限と見本残高の上限を設けます。
- 音は初期OFF。紙/チップ/玉の合成音と結果音、演出は通常/控えめ/即表示。動きを減らす端末設定を尊重し、非表示時は音と動きを止めます。没入表示は対応端末だけで使えます。
- 画面更新はGETだけ。連打で重ねて取得せず、通信失敗や入力エラーでも操作中の画面を残します。全画面中の画面切替でも全画面の親要素を維持します。

## ルーレットのBETから結果まで

円盤の数字へBET対象の光を追加。対象の計算は盤面の`rouletteMultiplier`を共用し、赤黒や境界も一致させます。回転中も円盤と一緒に光が動き、停止後の出目は白、当たったBETは薄緑で区別します。確定済みの盤面はチップと合計を保持して固定します。

新たな回転を操作したときだけ回転→結果→払戻の順で表示し、再読込・履歴から戻った結果は即表示。音とは別のタイマーで管理し、音OFFでも結果へ進みます。動き低減/即表示/結果スキップは数え上げを省略します。一般公開への接続は今回も含みません。

### 連続演出と結果の区別

全19ゲームに場面ごとの溜めの言葉、卓を横切る柔らかな光、配札/オープン、停止と結果の余韻を追加。「連続で演出を見る」は固定見本の4場面を進め、スキップ/停止/非表示/移動でタイマーを取り消します。音声の終了処理と進行を分け、音OFFで進行が止まらないようにしています。

実際の判定を持つ見本はwin/lose/draw、賭け先を選ばない役の表示はneutral、装飾の進行はdemo。負けには勝利の桜/ファンファーレを使いません。動き低減時は溜めの光や大量の桜を省略します。
