# 咲楽ノ宮の交流ゲーム（仮）設計書

> 状態: **設計中（まだ作っていない）**。2026-11-15 に方向を決めました。名前は仮です。
> この文書は、作る前に「何を・どの順番で・どう作るか」をそろえるためのものです。決まったら更新します。

## 1. 決まったこと（2026-11-15）

| 項目 | 決めたこと |
|---|---|
| ゲームの形 | **アバターで集まって話す交流空間**を土台にし、あとから **RPG の要素**（お役目・採集・作る・育てる・協力イベント）を足していく |
| 遊ぶ場所 | **Web のブラウザ**（カジノと同じく Discord でログイン）。スマホと PC の両方 |
| 銭との関係 | **サーバーの銭とつなげる**。着せかえ・家具・道具を銭で買える。遊ぶと少し銭がもらえる（1 日の上限あり） |
| 見た目 | **和風の、斜め上から見た 2D**（部屋を斜めから見る形。家具の置き方や奥行きが出る） |

- 作るのは咲楽ノ宮だけの**オリジナルのゲーム**です。ほかのゲーム（アメーバピグなど）の見た目・キャラクター・名前・音はまねしません。参考にするのは「アバターで集まって話す」という遊び方だけです。
- 遊べるのは**咲楽ノ宮のメンバーだけ**です（参拝者以上。運営が決めたロールでもしぼれる）。

## 2. どんなゲームか（ひとことで）

**「境内を歩いて、だれかとばったり会って話せる場所」**。
Discord の通話やチャットとはちがい、**同じ部屋にいる人のアバターが見えて、近くに行くと話しかけたくなる**場所を作ります。
そこに、毎日の「お役目」・庭での採集・家具や着物を作る・季節のお祭りの協力イベントといった RPG の楽しみを、少しずつ足していきます。

## 3. 世界のつくり

### 3.1 場所（部屋）

| 場所 | 中身 | 人数の目安 |
|---|---|---|
| 鳥居前の広場 | はじめに着く場所。掲示板・案内役の NPC・ほかの場所への道 | 30 人 |
| 境内 | 本殿の前。おみくじ・お賽銭（既存の機能とつなぐ）・季節の飾り | 30 人 |
| 縁側 | すわって話す場所。座布団にすわれる | 15 人 × いくつか |
| 庭・裏山 | 採集の場所（花・木の実・石）。RPG の要素の入口 | 20 人 |
| 宵宮（夜の場所） | 18 歳以上だけが入れる場所（入れるかは要相談。「6. 安全」を参照） | 15 人 |
| マイルーム（自分の部屋） | 1 人 1 部屋。家具を置いて、人を呼べる | 10 人 |

- 1 つの部屋に人が多すぎると重くなり、話しにくくなります。いっぱいになったら「縁側 2」のように同じ部屋をもう 1 つ開きます（今の Discord の自動で増える通話と同じ考え方）。
- 部屋の形は、ます目（タイル）で作ります。斜め上から見た形で、1 ますは 横 64 × 縦 32 ドットのひし形を基本にします。

### 3.2 アバター

- 体・髪・顔・服・小物を**重ねて**作ります（パーツを組み合わせるので、少ない絵でたくさんの見た目が作れる）。
- 向きは 4 方向（右上・右下・左上・左下）。歩く・すわる・手をふる・よろこぶ などの動き。
- 最初に無料のパーツをいくつか配り、ほかは銭で買う・お役目でもらう・季節のイベントでもらう。
- 名前の上に、役職（参拝者・氏子など）や称号を小さく出せる（既存の役職とつなぐ）。

### 3.3 話す・遊ぶ

- **チャット**: 吹き出しで出る（数秒で消える）。近くの人だけに見せる「ささやき」は最初は入れない（荒らし対策のため。あとで考える）。
- **エモート**: 手をふる・おじぎ・拍手・ハートなどをボタンで。
- **すわる**: 座布団や縁側にすわれる。
- **呼ぶ**: マイルームにフレンドを呼べる。部屋に鍵をかけられる。
- **音声**: 入れない。声で話したいときは Discord の通話を使う（ゲームの画面から「この部屋の通話を開く」リンクを出すのはあり）。

### 3.4 RPG の要素（あとから足す）

戦ってお金をかせぐゲームではなく、**集まって、少しずつ育てる**方向にします。

| 要素 | 中身 |
|---|---|
| お役目（毎日の小さなクエスト） | 境内の落ち葉はき・迷子の狐さがし・お供え物を届ける など。数分で終わる。終わると「徳」と少しの銭 |
| 徳（レベル） | お役目や採集で上がる。上がると着られる服・入れる場所・作れるものが増える |
| 採集 | 庭や裏山で、花・木の実・石・布などを拾う。日によって出るものが変わる |
| 作る | 集めたもので、家具・着物・お守りを作る。作ったものは市場で売れる（既存の市場とつなぐか要相談） |
| 図鑑 | 集めたもの・作ったもの・会った NPC を記録する |
| 季節の祭り（協力イベント） | 期間限定。みんなで力を合わせて「妖（あやかし）を鎮める」など。ボタンを押す時間（タイミング）や役割分担で協力する。だれかを負かす対戦は入れない |

- 銭でガチャを回して強くなるような作りにはしません（カジノとは分ける）。

## 4. 銭とのつながり

- **買う**: 着せかえ・家具・道具・マイルームの広さ。値段は運営が社務所Web で決める。
- **もらう**: お役目・採集・祭りの報酬。**1 人 1 日の上限**を決める（銭が増えすぎないように。前回のレポートで銭が 30 日で約 350 万増えていたので、増える量は小さめにする）。
- **ルール**: 銭は必ず `addCoins` / `spendWithin` で動かし、同じトランザクションで記録する。二重に払わない・渡さない作りにする（今までの機能と同じ）。
- **サブアカウント**: 承認されたサブアカウントは、銭をもらう・買う・渡すができない（今のルールと同じ）。
- 取り引き（人どうしで物をあげる）は、最初は「贈り物」だけ。売り買いは市場と相談してから。

## 5. 技術の設計

### 5.1 全体

```
ブラウザ（スマホ・PC）
  └ 画面: Canvas で描く（斜め上から見た部屋・アバター）＋ HTML（チャット欄・持ち物・ボタン）
      │  WebSocket（位置・チャット・エモートを、すぐにやりとり）
      │  ふつうの HTTP（買う・作る・持ち物など、記録が要る操作）
Web サーバー（今の社務所Web・カジノと同じ Hono）
  ├ 部屋サーバー（だれがどの部屋のどこにいるか。メモリの中だけに持つ）
  └ PostgreSQL（アバター・持ち物・マイルーム・徳・お役目の記録・チャットの記録）
```

- **ログイン**: カジノと同じ Discord ログイン（会員セッション）を使う。新しいログインの仕組みは作らない。
- **すぐに動くもの**（歩く・話す・エモート）は WebSocket で送る。位置はデータベースに書かない（メモリだけ。サーバーが再起動したら、みんな広場に戻る）。
- **記録が要るもの**（買う・作る・報酬）はふつうの HTTP の道で、CSRF と同時押し対策をする（カジノと同じ）。
- **描く**: Canvas 2D で自分で描く（軽く、絵の決まりを守りやすい）。足りなくなったら PixiJS を自分のサーバーから配る形を考える。社務所Web の CSP（外の script を読まない）を守る。
- **人数の目安**: 同時に 100〜150 人。部屋ごとに 1 秒あたり 10 回まで位置を送る。チャットは 1 人 3 秒に 1 回まで。

### 5.2 データベース（予定）

| 表 | 中身 |
|---|---|
| `world_avatars` | 人ごとのアバター（パーツの組み合わせ・色）・徳・最後にいた部屋 |
| `world_items` | アイテムの種類（服・家具・素材・道具）。名前・絵・値段・作り方 |
| `world_inventory` | 人ごとの持ち物と数 |
| `world_rooms` | マイルームなど、形を保存する部屋（家具の置き場所） |
| `world_quests` / `world_quest_progress` | お役目の種類と、人ごとの進み具合（1 日 1 回などの決まり） |
| `world_chat_log` | チャットの記録（運営が見返すため。書き込みの記録と同じく 90 日で消す） |
| `world_reports` | 通報（だれが・だれを・どの発言を） |

### 5.3 社務所Web（運営の画面）

- アイテムの登録・値段・販売のオン/オフ
- 部屋の開け閉め・人数の上限
- お役目と報酬の上限
- チャットの記録・通報の対応・ゲームの中だけのミュート/出入り禁止
- 遊んでいる人数・人気の部屋・銭の出入り（前回のレポートと同じように見る）

## 6. 安全とルール

- **18 歳未満の人を守る**: 宵宮（夜の場所）は 18 歳以上の確認ができた人だけ。マイルームに呼べるのは、相手が許可したときだけ。18 歳未満と 18 歳以上が 2 人きりになる鍵つきの部屋は作れないようにする（キャストの決まりと同じ考え方）。
- **荒らし対策**: 通報ボタン・ブロック（その人の吹き出しとアバターを見えなくする）・運営のミュートと出入り禁止。チャットの禁止語は、今の荒らし対策の設定を使う。
- **厄（警告）とつなぐ**: Discord で出入り禁止の人は、ゲームにも入れない。
- **記録**: チャットは記録し、運営だけが見られる。名前・ID を外に出さない。

## 7. 作る順番（案）

| 段階 | 中身 | 目安 |
|---|---|---|
| 0. 試作 | 1 部屋だけ。歩く・チャット・エモート。運営だけが試せる | 1〜2 週 |
| 1. 交流空間 | 広場・境内・縁側。アバターの着せかえ（無料パーツ）。通報とブロック。メンバーに公開 | 2〜3 週 |
| 2. 買う・飾る | 着せかえと家具を銭で買う。マイルーム。フレンドを呼ぶ | 2〜3 週 |
| 3. お役目と採集 | 毎日のお役目・採集・徳・図鑑・報酬の上限 | 3〜4 週 |
| 4. 作る・祭り | 家具や着物を作る。季節の協力イベント | 4 週〜 |

- 段階ごとに、運営が試してから公開する（今までのカジノと同じ流れ）。
- 目安は、ほかの依頼が入らないときの大まかな長さです。

## 8. 絵の準備

一番時間がかかるのは絵です。最初に決まりを作ってから描きます。

- 床のます目: 64 × 32 ドットのひし形。壁・家具はこれに合わせる。
- アバター: 高さ 96 ドットくらい。パーツごとに 4 方向 × 動き。
- 色: 咲楽ノ宮の桜色・藍色・夜の紫を基本にする。
- 作り方: 画像生成 AI で下書き → 決まりに合わせて手で整える。必要なら絵を描ける人にお願いする。
