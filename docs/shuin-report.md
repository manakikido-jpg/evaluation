# 御朱印の昇格条件の集計（読むだけ）

昇格に必要なご縁を考えるための集計です。**DB・Discord・設定は何も変えません。** 名前・ID は出さず、人数・中央値・分布だけを出します。

## 手順（VPS で）

1. VPS に入る（[デプロイの説明](deploy-vps.md) と同じ入り方）。
2. BOT のフォルダに移る（ふだん `docker compose` を打つ場所）。
3. 本番に、この集計が入っているか確かめる（本番ブランチを 15 秒ごとに取りこんでいるので、push から数分たてば入っています）。
4. 集計する（いまの条件と、暫定案を並べて出す）:

   ```sh
   docker compose exec bot node dist/scripts/shuin-report.js --plan 参拝者=0,氏子=15,世話役=50
   ```

   ファイルにしたいときは、うしろに ` > shuin-report.txt` を付けます。
5. 出た文をそのまま、チャットに貼ってください（名前・ID は入っていません）。

`--plan` を外すと、いまの条件だけを出します。役職の名前は、社務所Web で付けた名前でもキーでも書けます。

## 出るもの

1. いまの条件（社務所Web で変えた分もふくむ）と、各役職が押す朱印の点数。評価のリセットをしていれば、その日。
2. BOT・退出者を除く、役職ごとの人数（いちばん上の役職で 1 人 1 回）。
3. 直近 7 日・30 日（今日をふくむ日本時間）の浮上の人数と浮上率。
   - 発言: BOT が数えた発言が 1 回以上ある日がある（`activity_daily`）。
   - 通話: AFK などを除いた通話に 1 分以上いた日がある（`voice_usage`）。
   - 両方した人は「両方」に入れ、浮上の人数では 1 人と数える。
4. 役職ごとの「朱印をくれた人数」「朱印のご縁」「特別ご縁」「合計のご縁」「自分が押した相手の数」の中央値・25%・75%・最大と分布。取り消した朱印は数えない。直近 30 日に押した・押された人数。
5. 参加から氏子・世話役（以上）になるまでの日数。届いた人と、まだの人（参加してからの日数）を分けて出す。
6. いまの条件と暫定案で、各段階に届く人数。浮上した人・朱印をやり取りした人のうちの人数も出す。

## 偏り（読むときに気をつけること）

- 5 は、参加の記録（`member_events`）が始まる前に入った人と、評価のリセットより前の昇格を数えません。
- 退出した人は数えないので、早くやめた人が抜けます（日数は短めに出やすい）。
- 入り直した人は、最後に入った日から数えます。手でロールを付けた昇格は記録に出ません。
- 「まだ」の人は、これから届く人もいます（届かないとは限りません）。
