# 神符合戦・招待制無料βの準備（2026年11月11日）

本人が「招待制の無料β → 人同士で試遊・調整 → 一般公開」の順を承認した。初段階の参加許可と管理画面を追加した。実会員の登録・案内送信・本番合流・一般公開・有料化は実行していない。

## 運営が使う手順（本番反映後）

1. 社務所の **神符合戦（β管理）** を開く。経済ページの操作権限を持つ宮司・神職が、招待する人のDiscordユーザーIDを登録する。サーバー在籍を確認して登録し、変更は監査へ残す。まずは少人数で試す。
2. 同じ画面の **案内するURL** を本人へ渡す。登録だけではDiscordの投稿やDMを送らない。URLを知っていても、招待されていない一般メンバーは参加できない。
3. 本人がDiscordで認証して入る。/神符合戦 でも本人だけに入場ボタンを出せる。本人用の1回きりリンクは人に渡さない。
4. 終了した人や参加を止める人は **招待を解除** する。招待で入っていた人はログイン済みでも次のアクセスから拒否し、表示を閉じて対戦の席をCPUへ渡す。運営は招待不要なので、この解除は運営ロール自体を取り消す操作ではない。

βは無料で、本番の銭と別の霊銭だけを使う。招待しても運営画面・通常カジノの権限は付かない。入口・図鑑・API・本人用リンクで参加許可を確認する。Discordへの接続失敗も許可として扱わない。

招待対象は既存settingsのギルド別キーにDB保存する（新しいマイグレーションは不要）。2026年11月13日の追加で、対戦自体も専用テーブルへ保存する。部屋は作成から2時間（再戦で更新）まで、Web再起動・更新後も続きから戻れる。招待登録の仕組みはそのまま。対戦保存には新しいマイグレーション0163が必要。この保存期限を入口とロビーへ表示する。

実会員の人同士での試遊と、上限なしの回復を蓄積する戦法のバランス評価は未実施。完成したカード表示・固定操作・HP/MPの上限なしについては [UXの記録](shinpu-ux.md) を参照。

## 再確認

Node22・依存関係・Chromium・Playwrightを用意する。

1. `npx tsx scripts/previews/shinpu-beta.mts` を起動し「ローカル確認用」の表示を待つ。
2. `node scripts/previews/shinpu-beta-browser.cjs` を実行する。別の場所のPlaywrightを使う場合は `PLAYWRIGHT_MODULE` を指定する。
3. サーバーを停止する。

127.0.0.1:4212だけを使い、架空の運営・招待者・未招待者とメモリDBで確認する。Discord認証は偽物で、実Discord・実残高・秘密設定には接続しない。確認するのは登録フォーム、招待者のOAuth、未招待拒否、追加の特権Cookieなし、解除後の画面終了、遅れた応答による再表示の抑止。見本はdocs/previewsへ保存する。

従来のカード表示/攻防/上限なしのブラウザー確認も再実行する。`scripts/previews/shinpu-ui*.cjs` と `shinpu-ux-browser.cjs` は `SHINPU_SNAPSHOT_DIR` で確認画像を保存する場所を変えられる。

最終確認：型チェック・ビルド・全278ファイル3,008件のテスト成功（662.73秒）。ブラウザー4本が成功し、JavaScript例外0。Discord外部応答はローカルの代替実装で、実Discordでの認証・実会員による試遊は未確認。
