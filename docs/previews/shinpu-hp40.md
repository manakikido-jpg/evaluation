# 神符合戦：初期HP40と相手のHP表示

新しく始める対戦・再戦は、人間もCPUもHP40で開始します。MP12・霊銭20、HP/MP/霊銭の上限なしは従来どおりです。進行中の保存済み対戦の現在HPは書き換えません。満タン判定とHPバーの目安も初期HP40へ合わせています。

相手全員の現在HPを対戦画面の上部に常時表示します。自分の攻撃時にはHP欄を押して対象を選べます。対象選択ボタンにもHPを表示し、長い名前でもHPの数字が残ります。詳細一覧には大きい数値とHPバーを置き、正確な値を確認できます。大きな値は主画面だけ万・億・兆に短縮します。自分の手札以外の非公開情報は増やしていません。

## 確認したこと

- 新規対戦と再戦の開始HP40、初期MP/霊銭、40を超える回復、満タン境界39/40、保存済みのHP60の復元。
- HTMLの初期HPと遊び方、HPバーの目安の一致。
- 320×568、360×640、390×844、430×932、768×1024、1440×900、844×390で、通常・異なるHP・大きいHP/長い名前の21通り。
- 各HP値の表示欠けなし、盤面の数値/計算が隠れない、主画面の縦横はみ出しなし、クリックによる対象変更とキーボードのフォーカス、一覧のHP25表示。
- 攻撃・防御・候補選択・大きな資源値・通信断・結果の6状態×4画面寸法、基本8画面寸法でもはみ出し・JSエラーなし。
