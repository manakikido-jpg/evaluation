# 完成カードを活かした神符合戦UI（2026年11月11日）

これはカード画像の表示を改善した段階の記録です。後続の固定操作と上限なしの変更は [UXと上限なし](shinpu-ux.md) を参照してください。

本人の「せっかく画像つくったからそれ生かさないと」「それで作成してみて」を受けた変更。

- 手札と中央の選択札に、完成カード全体を表示。画像を切り抜かず、カード自身の枠・名前・数値・イラスト・効果を見せる。
- 重複していた画像外の名前・数値・説明枠を整理。各札の「拡大・効果」は選択を変えず、高解像度画像と文字の効果説明を開く。読み上げ用の名前・数値・説明も維持する。
- 中央の選択札は900px画像。手札は360pxの軽量画像。
- 自分の使用/防御札と公開された攻撃札はサーバー受理後に1.2秒の登場演出。拒否された操作には出さない。操作/計算を止めず、動きを減らす設定にも対応。
- カードの原画/数値/効果/ルール、運営限定、本番銭との分離は維持。本番未合流。

## ブラウザーで再確認する手順

Node22と依存関係、Chromium、Playwrightを用意する。秘密設定は不要。

1. `npx tsx scripts/previews/shinpu-ui.mts` を起動。「ローカル確認用」が出るまで待つ。127.0.0.1:4211だけで動き、メモリDBと架空会員を使う。確認の山札だけは乱数を固定する。
2. `node scripts/previews/shinpu-ui-browser.cjs` を実行。Playwrightを別の場所に用意している環境は `PLAYWRIGHT_MODULE` にそのモジュールのパスを指定する。
3. 続けて `node scripts/previews/shinpu-ui-two-player.cjs` を実行する。
4. サーバーを停止する。確認用Cookieと部屋は本番には使えない。

最初の検証は、画像読み込み/全手札の詳細/Enter選択とフォーカス保持/API拒否時の演出抑止/受理後の演出/動きを減らす設定を確認。2人戦の検証は、320/390/768/950/1440pxの横はみ出し・画像の縦横比と全体表示・複数札の攻撃/防御を確認する。画像はdocs/previewsへ保存される。

検証結果：型/build成功。全276ファイル2,982件成功（700.02秒、4worker）。上記ブラウザー検証2本も成功。JS例外/画像欠落/ページ横はみ出し0。本番には未反映。
