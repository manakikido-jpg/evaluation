# 神符合戦：スクロールしない対戦画面

スマホ縦持ちを基本に、対戦の主画面を画面の高さに収めます。主画面での縦スクロール・横スワイプは使いません。通常表示には上部のボタンで戻せます。

- 手札：前・次のボタンで2〜7枚ずつ表示。ページを変えても選択は保持。
- 相手：相手名のボタンから一覧を開き、選ぶと盤面に戻る。
- 選んだ札：ポップアップで3枚ずつ確認。回復先・属性・追加支払いの設定もここから開く。
- 防御：主画面にダメージと攻撃直後HPの見込み。詳細はポップアップ。
- 山札・売買などの候補：ポップアップで3枚ずつ選択し、その場で確定。
- その他：両替・様子見・参加者の状態・結果と記録・遊び方。

長い説明・記録・拡大画像はポップアップ内で閲覧します。ロビー・図鑑は通常の閲覧画面のままです。

## 見本

すべてローカルの架空の参加者・CPUによる画面です。本番のユーザー情報・残高は使っていません。

## 検証

- Chromium：320×568、360×640、390×844、430×932、768×1024、1366×768、1440×900、844×390。
- 6人対戦、攻撃・防御・候補選択・大きな資源値・通信断・結果の状態を確認。主画面の縦横のはみ出し、手札の縦横スクロール、確定ボタンの位置を確認。
- 手札全7枚のページ移動・選択の保持、相手の選択、拡大、回復先の選択、その他の操作、候補のページ移動と確定を確認。
- 2人のブラウザを使った攻撃の重ね選び・人による防御をローカルWebと保存済み対戦のAPIで確認。
- 候補札の確定ボタン単独の確認では、ブラウザの応答をテスト用に差し替え。実際の候補選択・売買・保存・再戦の計算は既存のサーバーテストで確認する。
- 実際のiPhone/Safari・Android端末および本番での確認は未実施。

[画面寸法・操作の確認結果](shinpu-viewport-checks.json) を保存しています。型チェック・最終ビルドは成功。全体3340件中3338件が成功し、時間切れ2件は対象の2ファイルを単独で再実行して27件すべて成功。関連42件と最終HTML/画像4件も成功。詳細は作業メモへ記録しました。本番合流・デプロイはこのローカル検証とは別です。
