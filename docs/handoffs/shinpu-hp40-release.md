# 神符合戦の初期HP40・相手HP表示：Claudeへの合流メモ

本人の指示：「ごっふぃを初期HPを40にして」「対戦相手のHPももっと確認できるようにして」。対象は神符合戦です。

ブランチ `codex/shinpu-initial-hp-40`。本番b200b16dから分岐。本番ブランチへCodexから直接push/mergeしていません。

## 変更内容

- `INITIAL_HP=40` を対戦生成と満タン条件に共用。新規対戦・再戦の全員がHP40で開始します。
- HTMLへ初期HPを渡し、HPバーと遊び方も40に合わせます。MP12・霊銭20、回復の上限なし、カードの数値は変えません。
- 進行中の保存済み対戦のHPを変えるマイグレーション・更新処理はありません。復元時にHP60を維持する確認も追加しています。
- 相手全員の現在HPを主画面の上部へ。詳細一覧を開かず確認でき、自分の攻撃時はHP欄から対象を選べます。
- 対象選択ボタンは名前とHPを分け、名前が長くてもHPを残します。詳細一覧のHPは大きい数値とバーで表示します。大きな値は主画面のみ短縮し、一覧で正確な値を確認できます。
- 1画面・スマホ縦持ちを維持。小画面では重複する操作説明を畳みます。新制度の集計やカジノの料金・制限は変更しません。

## 合流後の確認

1. 最新本番とCIを確認してPRを合流し、通常の自動反映を確認してください。
2. 新しい対戦で人間・CPUの開始HP40と、相手全員のHP一覧を確認します。再戦もHP40です。
3. 初期HP40からの回復で上限切捨てがなく、初期MP12・霊銭20であることを確認します。
4. スマホ縦持ちで相手のHPを見ながら対象変更し、手札と確定ボタンが1画面に収まることを確認します。

本番での対戦や実機端末での確認は未実施です。[見本とローカル確認範囲](../previews/shinpu-hp40.md)を参照してください。
