# 奉納中の宿の全開放（Codex → Claude）

本人の依頼：サーバーブーストに関しては宿の機能全開放。

## 変更
- `canUseRoomFeatures` を宿だけに追加。氏子以上、または在籍中のブースターが利用できる。
- 通話入口からの宿・シクレ作成と、パネルからの日/時間制の宿作成を対応。
- シクレに招待する相手自身がブースターなら、氏子未満でも招待できる。部屋主の奉納は他人に適用しない。
- シクレ招待は先に応答を保留し、選んだメンバーが取れない場合も確認してから許可する。
- ブースト終了後の新しい操作は通常の条件へ戻る。既存の部屋や入室許可の一斉削除は追加していない。

## 維持すること
- 24時間/時間制の無料と、通常宿の設定済み割引。銭の処理は変更していない。
- 厄・カテゴリの入室制限、作った人/運営だけの設定操作、人数/作成数など既存の決まり。
- カジノの位の条件は変更しない。新制度のスイッチは押さない。
- DB移行や追加設定は不要。コードの合流とBOTの更新で有効になる。
