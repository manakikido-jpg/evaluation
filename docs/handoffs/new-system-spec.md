# 新制度のまとめ（資料づくり用の引き継ぎ）

2026-11-27 時点。本人（宮司）が出した「新制度まとめ」と、Claude と一つずつ確かめた決定をまとめたものです。
資料（メンバー向けの案内・PDF・画像など）を作るときは、この内容を正とします。
決定の記録は [user-decisions.md](../user-decisions.md)、作業の経過は [work-notes.md](../work-notes.md) にあります。

**注意**
- 「実装」の欄が「まだ」のものは、BOT にまだ入っていません。資料に書いてよいですが、「準備中」と分かるようにしてください。
- 新制度は、宮司が社務所Web で③（絵馬での昇格）④（ご縁のリセット）を押すまで、メンバーには見えません。スイッチは Claude も Codex も押しません。
- 数字を変えるときは、本人に確かめてください。ここにない決まりを作らないでください。

## 1. 階級と昇格

| 段 | 条件 | 実装 |
|---|---|---|
| 参拝者 → 氏子 | 14日のお参り期間中に、必要な数の絵馬を集める。必要な数＝直近7日間に縁側で10時間以上いた氏子以上の人数の6割（切り上げ・最低1）。**2週間ごとに見直す**。招待で3つまで補える。招待した人が参拝者になると期間が1日のびる（上限なし） | ずみ |
| 氏子 → お世話役 | 選挙。候補＝氏子を3か月つづけ、氏子になってから縁側に120時間。条件がそろった週の金・土・日に #世話役選挙 で投票。投票できる人＝金曜0時に、直近30日の縁側が24時間を超えている氏子・お世話役・総代。その人数の6割を超える票で昇格。匿名・何人にでも投票できる。落ちたら縁側40時間でもう一度 | ずみ |
| お世話役 → 総代 | お世話役として絵馬を200集める（だれでも贈れる・期限なし） | ずみ |

切り替えのとき、今の役職はそのまま（決定 G）。

## 2. 絵馬

- 贈れる相手：縁側で1日30分以上いっしょに過ごした日が3日以上ある相手。参拝者どうしは不可。
- ひとこと：氏子以上は自由に書く。参拝者は定型文（話し手・聞き手・回し手・ムードメーカー）から選ぶ（自分で書いてもよい）。
- 贈り主は匿名。贈ったあと、書き直し・取り消しができる。
- 期限：参拝者が氏子に贈った絵馬だけ30日で切れる。
- `/絵馬` で、いま贈れる人・あと少しの人・その人との縁側の日数（○/3日）が分かる。
- 実装：ずみ。

## 3. ご縁・結び・招待

- ご縁は特典と交換するポイント。昇格には関係しない。
- 結び：縁側でいっしょになった、はじめましての人と結ぶ。1人につき +1（同じ人とは1回）。
- 招待：招待した人が通話に合計4時間いたら「1人」。1人につき +1。参拝者は5人目まで・氏子は10人目まで +2。お世話役はずっと +2。
- 招待の銭のお礼：招待した人が参拝者になったら150銭、氏子になったらさらに350銭。
- 使い道：貯めた数に応じた割引・倍率アップの特典。**中身は未定**（今は節目で銭・称号がもらえる形のまま）。
- 実装：結び・招待はずみ。特典の交換はまだ。

## 4. 氏子のキープ・元氏子・お守り（実装：ずみ）

- 氏子でいるには、判定の日に有効な絵馬が20（うち10は参拝者から）。招待で5つまで補える。
- 判定は、氏子になった日から30日ごと。切り替え前からの氏子は、切り替えた日から30日後が最初。
- 足りないと BOT が自動で「元氏子」にする（判定の7日前に「あと◯枚」を DM）。お守りがあれば1回防げる。元氏子が贈った絵馬は「参拝者からの絵馬」として数える。
- お守り：30,000銭（授与所で買う・氏子だけ・今週か先週の分を買える）。1週間に縁側で40時間以上過ごした週に1個買える。最大3つ。降格しそうなときに自動で使う。判定2回つづけては防げない。
- 元氏子：扱いは参拝者と同じ。絵馬はリセット、ご縁はそのまま。絵馬15（うち10は参拝者から・招待で5つまで補える）で氏子に戻る。元氏子は参拝者・氏子のどちらにも絵馬を贈れ、その絵馬は氏子のキープ・参拝者の昇格に数える。
- お世話役は、ふだんのキープ条件では下がらない。
- 元氏子のロールは、宮司が Discord で作って社務所Web に ID を入れる。入れるまで BOT は降格しない。

## 5. 荒魂（評価落ち）（実装：ずみ）

- 14日で氏子に上がれなかった参拝者は、運営の判定（延長／氏子にする／荒魂にする）で「荒魂」になる。
- 荒魂になってから3人招待すると、BOT が自動で参拝者に戻し、14日を最初から始める（何度でも）。招待は、招待した人が4時間浮上したら1人。
- できること：縁側、宿への参加（作れない）、カジノ（上限500銭）。
- できないこと：絵馬を贈る・受け取る、結び、宿を作る、シクレ、キャストの給仕と利用。

## 6. 厄

- ルール違反への警告。1つで厄年、2つでBAN。重大な違反は一発BAN。
- 厄のあいだ：通話は縁側だけ。使えるのは、お問い合わせ・おみくじ・物御籤・授与所の免罪符・カジノ（上限500銭）。絵馬・結び・宿・シクレ・キャスト・送金・市場・お年玉などは不可。
- 「1時間につき-30銭」は入れない（決定 B）。
- 消し方：①免罪符（10,000銭・1人1回・厄が付いて1週間たってから買える）を買う → ②運営との面談 → 運営が厄を祓う。
- 実装：ずみ（カジノの上限は「1日の合計500銭」）。

## 7. ロールごとの決まり（カジノ・宿）（実装：ずみ。参拝者専用の大勝負の札だけまだ＝値段が未定）

カジノの上限は「1日に賭けられる合計」です（1回の賭けの最高は別の設定）。


| ロール | カジノの上限 | 宿 | シクレ |
|---|---|---|---|
| 厄 | 500銭（ずみ） | 不可 | 不可 |
| 荒魂 | 500銭 | 参加だけ | 不可 |
| 参拝者・元氏子 | 5,000銭（参拝者専用の大勝負の札で2万まで。ほかの札は不可） | 参加だけ | 不可 |
| 氏子以上 | 2万銭 | 作成・参加 | 作成・参加 |

氏子以上は役職（案内人・衛士・祭長・編集者）に応募できる。階級が上がると、通話でもらえる銭と1日の上限も上がる。
