# 縁側の個人用操作パネル：Claudeへの合流メモ

本人がrain銀行風の見本に「それでいいね」「それで作成してみて」と了承し、続けて「寝落ち報告と運営を呼ぶもこれに追加」と依頼。装飾画像は使いません。

対象ブランチは `codex/new-system-bot-ui`。本番への直接pushやVPS操作はCodexで行っていません。

## 変更内容

- 縁側の共有入口を「操作パネルを開く」へ変更。押した本人だけにComponents V2の行形式で7項目を表示します。
- プロフィール・ご縁は同じ通話の人の一覧から既存のプロフィールへ。絵馬は既存の自分の絵馬画面へ。コマンドは役職に合わせた既存一覧です。
- 送金は相手選択→金額入力→既存の50％手数料を含む確認→確定。運営免除・料金・条件・二重決済防止は既存サービスを使います。
- 寝落ちは対象者選択、運営呼び出しは任意の状況入力を経て既存の衛士通知を利用します。元の通知先とクールダウンは変えません。通知処理の前に応答を保留します。
- 個人パネルの本人・元の縁側チェック、新制度の③④での非公開制御、厄制限を維持します。新しい個人通報メニュー・モーダルでも本人・同じ通話を確かめます。
- 縁側以外の共有パネル、隠す通話・カテゴリ、宿坊除外などは既存どおりです。共有カードは従来と同様、出し直す際に前のものを消します。

## 合流・確認

1. PR差分とCIを確認し、最新本番を取り込んだ内容で型チェック・全テストを確認して合流します。
2. 自動反映後、運営アカウントで縁側へ入り、共有入口→本人限定の表示を確認します。
3. 新制度の公開設定は変更しません。公開前はプロフィール・送金・コマンド・寝落ち報告・運営呼び出しの5項目、③④の公開後は7項目です。
4. 送金は確認画面まで開いて、料金を確認します。実際の決済や衛士への通報は、運営がテストすると決めた場合だけ行ってください。
5. 別通話へ移動した後の旧個人パネルは利用案内だけを返すこと、共有カードが重複しないことを確認します。

実際のDiscordへCodexからテスト通知・送金を行っていません。[見本と送信データ](../previews/engawa-control-panel.md)は実装から生成した近似表示です。
