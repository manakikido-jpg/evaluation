# 競馬の合意・大型アップデート仕様と実装順

2026年10月27日更新。従来のUI合意と、末尾の大型アップデート採用仕様をまとめます。最新の工程は8頭のリアル調3D試作から始めます。

## 合意した方向

- 咲楽ノ宮らしさは濃紺の漆、薄い和紙、くすんだ桜色、朱印風の状態表示で出します。鳥居・石灯籠・絵馬は背景の案です。
- 券種名・馬番・金額は、実際の競馬に近い分かりやすい表現を保ちます。分かりにくい神社用語に置き換えません。
- 単勝・複勝・馬連・ワイド・馬単・3連複・3連単の7券種を選び、馬番、ボックス／着順指定、1点の金額、点数、合計、買い目を確認する構成です。
- 着順指定は、押した順だけに頼らず「1着→2着→3着」の選択欄を検討します。フォーメーションは現行実装にない追加案です。
- 競馬の順位を左の縦表示から映像の上部へ移します。PC・スマホ横画面の両方で順位と馬番を分け、馬名を添え、購入した馬を強調します。
- PCは競馬画面の横幅制限を外し、ブラウザーの表示領域を広く使います。右の馬券欄の幅は操作しやすく保ち、映像へ余った幅を配ります。
- ユーザーはレース画面の横向き必須でもよいと述べています。横向きを基本にする方針ですが、端末回転の強制は採用していません。厩舎・成績まで横向き必須にするかは未決定です。

## 今回の反映範囲

順位欄を映像の外側・上部へ置きます。受付中・発走前は順位と混同しない表記とし、発走後は途中順位、結果演出では到達順位から確定着順に切り替えます。購入した複数頭は桜の目印で示し、口取り式でも順位を残します。短いスマホ横画面では情報の高さを抑え、賞金の詳細条件は開閉して確認できます。

PCは表示領域の幅を使い、映像の高さも調整します。賭け方・オッズ・賞金・馬の能力・血統・共同所有・DBの処理は変更しません。濃紺の観戦枠と和紙色の順位欄を入れますが、採用見本全体の配色変更や馬券入力の作り直しは次の改修です。

## 次の改修候補

1. 馬券入力を投票用紙風に整理し、点数と合計を常に確認できるようにする。
2. 着順指定の操作を分かりやすくする。
3. 受付中は出馬表と購入、レース中は映像と購入済み馬券、結果は着順と自分の清算を中心に表示する。
4. 馬主の部屋を、馬の一覧と今できる操作が分かる構成にする。

## 2026年10月27日採用：大型アップデート

ユーザーは次の5項目とリアル調3Dの方向・実装順を採用しました。既存の調教/疲労/配合/共同所有/称号/重賞を土台に拡張します。

1. 演出：実馬に近い体形・走法・毛色・騎手・勝負服、芝/ダート/天候、発走/追走/ゴール/リプレイ。実況は走行データの出来事に連動、写真判定は実際の接戦だけにする。
2. 育成：スピード/スタミナ/スタート/パワー/折り合い/休養の選択、履歴と疲労・成長傾向の表示。スキルは二の脚/折り合い上手/長くいい脚/重馬場巧者/勝負根性など。初期案は装備2枠・条件付き発動で、効果と成長に上限を設ける。
3. 馬主：記録に基づく血統表/祖先の戦績/配合予想/一部継承。共同所有の持分・配当・費用・操作権限・履歴を見える化。称号と馬主プロフィールを拡張する。現在の馬/戦績/持分を引き継ぎ、確認できない祖先は不明と表示する。
4. イベント：季節重賞、シーズンリーグ、新馬大会、条件戦、馬主対抗戦。馬/馬主/種牡馬のランキングと、称号/記念カード/勝負服等の報酬。社務所で日程・条件・ポイント・報酬を設定する。
5. 馬券/収支：7券種の通常/ボックス/フォーメーション、着順別の選択、買い目/点数/単価/合計の購入前確認。購入済み馬券、的中/購入額/払戻/差引収支、馬主の賞金/手当/配当/調教/出走/繁殖費を整理する。

料金・倍率は少人数/無投票/共同所有等の試算を見て別途決定します。仕様採用だけで新しい額を本番へ適用しません。

### ビジュアルと端末

リアル調3Dと競馬中継を目標にし、桜の競馬場・濃紺と金・和紙風の情報欄で咲楽ノ宮らしさを出します。馬番/着順/オッズの表記は競馬として分かりやすく保ちます。PCと横スマホは左に映像・右に馬券、上に順位。厩舎/血統は縦でも操作可能にします。

画質切替と軽量表示を用意し、スマホ30fps/PC60fpsは実機測定して調整する目標値とします。馬の筋肉/四肢/接地/たてがみ/尻尾、騎手の前傾と追い動作、芝/砂の見分けを優先します。写実性の完成は、形状・素材・走法・光を試作で確認してから判断します。

### 工程と受入条件

- 第1段階：8頭の3D試作。全景/直線追走/ゴールの3場面を同じ走行データで確認。再生/停止/シーク、画質切替、WebGL不可の軽量表示、スマホでの表示と計測を用意する。サンプルであることを明示し、銭や実馬の戦績を動かさない。
- 第2段階：本番走行データへの接続、実況、発走/ゴール/結果演出。結果の整合、同じ時刻の同期、未来の展開の公開制御、再接続を検証する。
- 第3段階：馬券/収支の操作改善。点数/合計の整合、締切/二重購入/払戻、端末別操作を検証する。
- 第4段階：育成/スキル。上限/疲労/継承と既存馬の引継ぎ、実レースへの効果を試算する。
- 第5段階：馬主機能/大会。既存持分/配当/履歴を引き継ぎ、イベントの集計・同着・報酬の二重付与を検証する。

現段階の納品は第1段階の試作と仕様記録です。第2段階以降や価格決定、完成版の写実性まで達成済みとは扱いません。
