# 神殿スロット：無料試遊の仕上げ

2026年11月3日。対象は `trial-2` の運営向け無料試遊。実際の財布、一般公開、本番への合流は含まない。旧 `trial-1` の乱数列・試算を維持する。

## 今回追加したこと

- 表モード8種（低確1・低確2・通常・準備・V・天国ショート・ロング・超天国）、裏モード3種（低確・準備・天国）。区間・設定・成立役から移行とGG当選を判定する。Vでの通常当選は3セットを前兆へ確保する。
- 表/裏の当選、本前兆/GG/SGGの上乗せ、履歴、GOD/赤7、G-STOP図柄揃い/リーチ目の追加ループ。複数の当選は各権利を保ち、同じ当選の基礎セットを重複計上しない。
- 通常SGGに加え、メデューサとEXの赤7巻き戻しループ。メデューサは止めた残りGを参照し、通常SGGは消化後の残りGを参照する。EXのフェイク赤7は直接の上乗せ対象から外した。
- G-STOPの8群、成立役別の鏡個数、鏡の停止・変化、HOLDの候補絞り。HOLDはVSV/SVS/7S7/S7Sのみ。リーチ目は135/175/315/753/V31。GODではG-STOPを終了し、戻り先へ確定権利を渡す。
- 設定変更を受け付けたPOSTで、開始モードと510/1000/1480Gの天井を一度だけ抽選して予約保存する。通常の離席後・ボーナス終了後に反映。GG開始で通常天井1480Gへ戻す。
- 天国ショート、裏天国、GG中の鏡高確の確認場面。自然抽選の成績と区別する。

## 保存と判定順

- 成立役とG-STOP候補はレバーで保存し、STOPで止まった位置も保存する。通常のモード/当選/追加ループは最後のSTOPで確定する。途中の再読み込みで引き直さず、同時POSTはDBロックとrevisionで1件だけ受け付ける。
- 試遊では「開始時のモードで当選判定→次のモードを保存」。表/裏は独立。G-ZONEはストック/前兆権利があれば本前兆の表、なければ通常の表を使う。G-STOPとG-ZONEの裏抽選は行わない。
- 通常の本前兆中の追加当選は `omenStocks` へ足し、前兆を延長しない。追加ループは次のゲームから各1回ずつ進め、落選で終了。前兆中なら当選済みの権利へ足す。未消化の継続率はセット数・払出と混ぜない。
- 旧 `sggLoops` と天井ループは維持し、それ以外を `bonusLoops` で保存する。ループだけ残っても1時間保護・本人保存の対象。受け入れた別台の元の状態を消さない。
- 旧保存で表/裏モードがなければ低確1/裏低確、天井がなければ1480Gとして続行。過去の当選を遡って付けない。旧設定予約に抽選結果がなければ低確1/1480Gを採用し、GETで乱数を使わない。
- 新設の試遊台・「通常時」の場面は低確1/裏低確/1480G。設定リセットとは分ける。設定変更後の裏は低確とする試遊規則。
- 内部モード、HOLD候補、予約時の抽選結果、当選前の継続率はHTML/表示用データに出さない。本人の保存状態も別ユーザーへ渡さない。

### 丸め差・資料差

- モード表は百分率を1000倍し、10万通りで抽選。合計の差が0.15ポイント以内なら最大の項目だけに丸め差を戻す。それを超える表はエラーにし、勝手に全項目を縮小しない。設定別の小数桁が異なる資料もあるため、メーカー内部の分母を推定した値とは扱わない。
- なな徹の通常モード・右上がり黄7に合計100%を超える値がある。設定1/2/4/6の準備移行は必勝本の22.34%を採用。通常モード・中段黄7の準備92.97%はなな徹を採用（必勝本は92.67%）。
- GG中低確2・共通右上がり黄7の「ロング0.2%」は、他の行だけで100.01%となる。試遊ではこの余分な項目を採用せず、低確2/通常/準備/ショートの表とする。ここは原資料の訂正確認が必要。
- 準備中のGOD/赤7は、必勝本の「移行せず96.88%」を採用する。なな徹で通常と表示される欄との差を残す。G-STOP中のVは確定役でも維持する表を採用し、通常のV当選はショートへ移す。
- 裏の本前兆/GG/SGG中の設定別見出しに重複があるため、固有欄の設定4/6を優先し、共通欄を設定1/2/3/5へ適用する。
- 追加ループ表は頂の小数第2位までの値を採用。天国ロングの通常当選は、なな徹のテーブル9を採用（頂の一部表はテーブル3相当）。GODはG-STOP中を表4、それ以外は表10とする試遊規則。GG/SGG中のGOD専用の確定的な差分は未確認。
- メデューサ巻き戻しは一撃の表を採用。残り0/7/11Gは強い表、それ以外は中間の表。EXは残りGによらず弱い表。必勝本のメデューサ「その他」とEXの別ページに異なる記載があるため、実機の確定仕様とは断言しない。
- 設定6のリセット天井は公開値の合計が100.01%。510Gを10%、1480Gを4.69%に固定し、1000Gを残り85.31%とする。

### まだ実機と同じと断言しない部分

- GG中G-STOPの鏡高確へ入る割合は確認できていない。自然試遊は鏡低確を使い、高確の群は場面確認だけで使う。高確の当選率を自然試算へ混ぜない。
- HOLDで候補が減る際の非当選図柄の内訳は未確認。試遊では当選図柄を必ず残し、他の図柄は固定順で残す。残り個数からの当選率（1/個数）は公開表に合わせる。旧HOLD保存に群がなければ鏡なしの対応群を使う。
- EXと時間停止の同時成立は既存の試遊規則を維持（EX中は新規時間停止を引かず、メデューサ巻き戻しでEXへ昇格）。裏や履歴など独立の当選は残す。
- 成立フラグの概数、目押し補助、G-STOPの下部押し順補助、当選/移行の処理順、履歴当選の即告知等はモデルの前提。小役の細分類、前兆演出、押し順ミス時の内部抽選まで完全再現したものではない。
