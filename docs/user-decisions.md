# 作業ルールと神符合戦の決定事項

2026年10月18日更新。ユーザーから受けた作業ルール・指摘・合意を引き継ぐための資料です。作業前に [AGENTS.md](../AGENTS.md) とこの資料を読み、最新のGit状態・PR・仕様を確認してください。新しい明示的な指示がある場合は、その指示を優先して資料も更新します。

## リポジトリで作業するとき

- 本番ブランチ `claude/compassionate-sagan-8fqy8p` には直接pushしません。pushすると数分で本番に反映されます。
- `codex/〇〇` の作業ブランチで作業し、そのブランチへpushして本番ブランチ向けPRを作ります。Claudeが確認して合流します。
- 開始前とpush前に `git fetch` し、本番ブランチの最新変更を取り込みます。
- push前に `npm run typecheck` と `npm test` をすべて通します。テストを削除・skipしたり、無理に通したりしません。
- force push・rebase・履歴の書きかえはしません。
- `.env`・`config/guild.json`・トークン・パスワード・`WEB_ENTRY_KEY`・`BACKUP_WEBHOOK_URL`・`BACKUP_PASSPHRASE`・VPSのIPは読まない・書かない・出力しません。公開リポジトリに秘密の値を保存しません。
- 変更時は `src/changelog.ts` の先頭に更新を追加し、決めたidを変えません。`docs/admin.md` と関連テストも更新します。
- DBの形を変える場合は `npm run db:generate` で新しいマイグレーションを追加します。適用済みのものは変更しません。
- 社務所WebのCSPを守ります。インラインのscript・onclick・style属性を使わず、JSは `src/web/public/` と `assets.ts` で管理します。
- 銭の移動は `economy.ts` の `addCoins` / `spendWithin` を関連処理と同じトランザクションで使います。
- 新しい設定には `src/config.ts` で `.default()` を付け、`POST /settings` で既存設定を `prev.〇〇` により保持します。
- 完了時は「何を・なぜ・どう確かめたか」とテスト結果、作業ブランチ・PRを短く伝えます。
- 分からないことはユーザーに確認します。すでに許可された範囲の作業は進めます。

## カードのデザイン

ユーザーが採用した方向は、濃紺の漆・銀の枠・控えめな金・武器が主役のデザインです。

- 初期の見本への指摘は「情報が多い」「周りがださい」。ベージュの帯と単純な金縁は不採用です。
- 背景・水流・狐・桜をすべて目立たせず、武器を見分けられる構図と余白を優先します。
- 名前・属性・数値を枠に自然に組み込みます。上下に別の帯を貼ったような見た目を避けます。
- 小さな手札と拡大表示の両方で確認します。似た武器は形と構図で区別します。
- 通常札の装飾を抑え、希少札で特別感を出す方向を検討します。具体的な装飾段階はまだ未確定です。
- 画像に文字を含む完成見本と、ゲームで使う絵素材を区別します。WEBへの組み込みでは名前・数値・効果をデータから表示する方針です。
- 既存画像は削除・上書きせず、新しいデザインは別に保存します。

## 追加攻撃の最新ルール

ユーザーはゴッドフィールドの追加攻撃方式に合わせることを承認しました。

- 通常の攻撃札（＋なし）は一度に最大1枚。
- その1枚に＋付きの追加攻撃札を重ねられます。＋付きだけの攻撃も可能です。
- 防御札は＋なしでも複数枚使えます。
- 攻撃・防御の3枚制限は外し、手札とMPの範囲で使います。
- 攻撃札と防御札は混ぜません。回復・道具は単独使用です。CPUも同じ条件に従います。
- 最初に＋付きにするカードは紫電の短刀。試作のidは `blade`、237枚案では `SK-038` です。

以前の「複数選択はすべて＋必須」「最大3枚」という案は撤回済みです。[PR #43](https://github.com/manakikido-jpg/evaluation/pull/43) の最新差分を確認してください。PR作成だけで本番反映済みとは扱いません。

参考として、2026年10月1日の[非公式公開スナップショット](https://github.com/BrandenXia/godfield-bot/blob/main/data/snapshots/2026-10-01/api-catalog-en.json)では攻撃の＋指定が30種類（武器21・防具4・雑貨1・奇跡4）でした。防具の＋も攻撃用の指定です。30種類すべてをこちらに割り当てた状態ではありません。[通常と追加武器の説明](https://w.atwiki.jp/piong/pages/15.html)と[防御の説明](https://w.atwiki.jp/piong/pages/17.html)も照合資料です。
