## 実端末で行う手順

iPhoneはSafari、AndroidはChromeで同じ手順を行い、端末名・OS・ブラウザーの版と結果を記録します。試遊の実装が反映された後、「最新の状態を確認」で再読込します。

1. 音OFFで着席し、縦横に回して、液晶・レバー・3STOPを確認します。横向きは「操作に集中」を使い、画面端や安全領域に停止ボタンが重ならないか見ます。
2. 音ONで20ゲームほど連続操作します。停止音が大きく遅れて鳴らないか、回転音が重複せず最後のSTOPで止まるかを聴きます。端末スピーカーと普段使うイヤホンで、小さめ/ふつうの音量を比べます。
3. 全停止後、場面確認でGGやSGGを選びます。設定の変更そのものは切替演出を鳴らしません。通常のゲーム進行で区間が変わるときに短い演出が入り、演出中も次の操作へ進めることを見ます。
4. 当選演出見本で音の重なりと音量変更を確認します。実際の当選では上部→側面→GODパネルの順に光ることを確認します。見本はポイントや進行を変えず、実際の当選と区別します。
5. 回転中と当選演出中のそれぞれで、別タブへの移動と画面ロックを試します。隠れたら音が止まり、戻っただけで古い当選音が再演しないことを確認します。音が戻らなければ音ONや操作ボタンに触れ、停止済みの操作を再送しないでください。
6. 「控えめ」「即表示」とOSの動作低減で、扉や発光を省いて結果を読めるかを見ます。戻る/進むでページを復元した場合も古い光や音が再開しないか確認します。
7. 5〜10分使い、操作の遅れ・極端な発熱・音の途切れが出るかを記録します。ブラウザー検証から実端末の発熱や電池持ちを推定しません。

## 操作感・設定・再開の追加確認

集中表示でも「設定」を開き、音量・演出・発光・画質・映像の待ち時間を変更できます。「停止音を確認」はポイントやゲームを進めません。音が映像より後から聞こえるとき、映像の待ち時間を標準/40ms/80msで比べます。実機の音声出力やイヤホンの遅れは未確認で、設定値が端末の遅れそのものを測る機能ではありません。

画質「自動」は表示中の動作が重いときに装飾の粒子・ぼかしなどを減らします。自動判定はテストで遅いフレーム列を与えて確認し、実端末の性能・発熱・電池持ちの改善を測ったものとは区別します。「通常」「軽め」を手動で選べます。

- 設定を開いたままSpace/1/2/3がゲームへ送られないことを確認します。
- 確認音を鳴らして設定を閉じ、古い確認音やランプが残らないか確認します。
- 通信待ちの間に設定を開いた場合も、応答後に選択内容と入力中の項目が保たれるか確認します。
- STOPを押した直後の押込み表示と、確定した停止音/映像を比べます。実機の聴感は別途記録します。
- 中断から戻ると「停止待ち：中STOP」などが出て、自動で操作を再送しないことを確認します。
- 停止待ちのまま再読込しても、公開された停止位置から案内するか確認します。
- 構図・光の流れ・短い音の装飾差は、成立役や当選率・獲得セットの違いを示すものではありません。

## 操作の待ち時間を比較する

1. 設定→「操作の時間を確認」→「記録開始」で、設定を閉じて数ゲーム操作します。直近20操作だけが残ります。
2. 同じ設定画面で入力待ち/応答待ち/画面更新/表示までの目安を比べます。通常/軽め/即表示などの条件を変える場合は記録を消してから測ると比較しやすくなります。操作の途中で設定が変わった記録は中央値に含みません。
3. 必要なら「結果をコピー」で共有用のテキストを取り出します。コピーできない場合は表示されたテキストを選択します。記録は外部送信・永続保存せず、再読込で消えます。
4. 別タブへ移動した操作や失敗は区別されます。「記録停止」「記録を消す」は試遊の進行を変えません。

表示までの目安は2回目の描画コールバックまでです。実描画・停止演出完了・音の聴こえ始め・実端末の遅延を測定した値ではありません。入力待ちは指を離す時間、応答待ちは通信/サーバー/ブラウザーの実行待ちも含むので、その数値だけで原因を決めないでください。実iPhone/Androidの聴感や操作感は上記の実端末手順で別途確認します。
