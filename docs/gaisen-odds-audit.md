確認日：2026-10-28（日本時間）。対象：本番合流済み01d9231の `trial-1` エンジン。今回の変更は検証処理・資料のみで、無料試遊の抽選・払出・保存データは変更していない。

**判定：現行のまま一般公開・実際の銭への接続へ進めない。** 通常時の高い払出、区間共通の役抽選、SGGの赤7確変が未搭載であることをコードと試算で確認した。機械割を狙った値へ丸める調整より、区間ごとの小役・履歴抽選・モード・天井を先に照合して組み直す。

## 再現方法と測定条件

```sh

```

- [結果JSON](gaisen-odds-audit.json)にエンジン/試算コードのSHA-256、seed、条件、各試行と集計を保存。日時などの非決定的な値は含めない。DB・環境設定・秘密・Discordを読み込まない。試遊ページのオートプレイを追加するものではない。
- 長期：設定1〜6、それぞれ100万G×3seed（71・2026・449）、合計1,800万G。通常は左中右、画面にナビが出る黄7（GG・SGG・G-ZONE）だけナビに従う。G-STOPは左中右、HOLDは中だけ。未停止の隠れた押し順を通常時の利益に使わない。
- 操作比較：各設定10万G×3seed×3条件（ナビ遵守・常に左中右・ナビ時だけ必ず間違える）、計540万G。条件ごとに状態遷移も変わるため、途中から同一の役列とは限らない。
- 短期：各設定1,000G×100seed（10001〜10100）、計60万G。毎回通常0G・10万ポイントから開始。長期と合わせて**2,400万G**。強制当選や場面見本を収支に混ぜない。
- 払出率＝`output / input × 100`。1G30を投入し、リプレイ時は30を返す現行モデル。リプレイ返却が投入/払出の両辺に含まれる。`paidInput/paidOutput`には返却を除いた値も保存。実機媒体の機械割と定義が同じとは断定しない。
- 資金不足なら試算上のみ10万を補充。補充は払出・純収支に数えず、`finalBalance = initialBalance + refillPoints + output - input`を毎G検証する。最後の未消化GG・ストック・前兆・特殊区間は別記し、払出へ換算しない。
- 乱数は旧試算と同じ再現用LCG。実プレイは暗号乱数であり、このseed列は実プレイの結果を予測しない。表の範囲は試行間の観測範囲で、信頼区間ではない。短期は通常0Gからの成績であり、既に当たっている台を選ぶ場合とは異なる。

## 収支の原因を区間で分ける

現行の全65,536フラグと6押し順を列挙した1G期待値は、通常時に払出24.951ポイント、差引 **−0.505枚相当/G**。うち3枚役だけで11.400ポイント/Gを戻している。通常でも3枚役を全払いする単純化が、通常区間を非常に減りにくくしている。

ナビを守ったGGは払出52.451ポイント、差引 **＋2.245枚相当/G**。設定1の自然抽選実測は通常−0.507、GG＋2.255枚相当/Gで、列挙値と近い。通常時のベース、当選頻度、GG比率の組合せで全体の高い払出率になっている。SGGだけの確率を上げるとさらに全体の出方が変わるため、先に区間別役分布・払出をまとめて修正する。

この期待値は「当該1Gの払出」であり、その1Gに獲得する将来のGG権利を金額評価したものではない。区間の入力・出力・役別の払出はJSONの`byPhase`、区間移行は`transitions`にある。

## 修正順と次の合格条件

1. **区間別の役・払出モデル**：通常とGGのベースを分離。3枚役・1枚役・押し順黄7・青7/赤7のリプレイを資料と突き合わせる。G-ZONEとG-STOPは復帰元を含めて定義する。
2. **SGGの赤7と履歴抽選**：SGG通常/メデューサ/EX、通常/ATの青7・黄7連を分ける。G-STOP中の再当選を即座に上書きせず、待機権利を定義する。
3. **モード・天井・ループ**：設定別の表と前兆を定義し、出典と未確認部分を保持する。通常のサーバー再起動で設定リセットを起こさない。
4. **版と保存権利の扱い**：現行保存は`trial-1`で、設定キーは`casino.gaisenTrial.v1`。次の抽選版へ切り替えるとき、回転途中/本人保存/退避中の台を無断で初期化しない。旧ボーナスの完了まで旧ルールを保持するか、別の試遊台に新ルールを用意する設計が必要。
5. **再試算と確認**：同じseed/条件に加え追加seedで比較。役の合計・払出期待値・履歴境界・天井直前/同時当選・SGG末尾・保存再開を検証。平均だけでなく短期分布と未消化権利を見る。目標値へ合うまで都合のよいseedを選ばない。

一般公開の判定はこの監査の完了とは別。抽選表の主要差分、保存権利の移行、運営用の復旧手順、料金と経済への影響が未解決のため、今回は無料試遊の範囲を維持する。
