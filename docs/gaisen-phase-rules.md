## 抽選モデル

`src/services/casino/gaisen/phaseRules.ts` に通常・GG・SGG・SGG高確率の4表を分離しました。前兆/G-ZONE/通常へ戻るG-STOPは通常表、GGへ戻るG-STOPはGG表、SGGのメデューサまたはEX中は高確率表を使います。

抽選空間は2の24乗。GODは1/8192、共通赤7は12/65536を保持します。その他は公開資料の分母から確率を計算して整数へ丸めます。中段/非中段の共通赤7、SGG逆押し赤7、フェイクA/Bはそれぞれ合算し、個別の内部フラグ・リール制御までは再現しません。

| --- | --- |
| 通常 | 上段青7 1/7.9、下段黄7リプレイ1/17.4、1枚A 1/10.4 |
| GG | 上段青7 1/5.4、押し順15枚1/4.4 |
| SGG | 上段青7 1/21.9、逆押し赤7は1/29.5＋1/206.6、逆押しフェイク1/10 |

| 共通 | 特殊1枚B 1/102.4、C 1/409.6、中段青7 1/99.9、左始動右上がり黄7 1/57.7、押し順不問右上がり黄7 1/655.4、中段黄7 1/936.2、フェイク2/655.4、特殊SP 1/65536 |

通常のハズレ、AT中の3枚役は残りの確率を割り当てます。公開資料の約1/1.5・約1/1.8は粗く丸められており、全項目を独立に足すと1を超えるためです。全体を再正規化してGODなどの確率を変えることはしていません。採用した整数ウェイトは試算JSONに全件保存しています。これを実機内部の正確なウェイトと呼ばないでください。

## 戻り・操作・表示

- 1G30ポイント、1枚相当10ポイント。リプレイは全種類30返却。通常の下段黄7もリプレイで、通常時の3枚役全払いは廃止しました。
- GG/SGGの押し順15枚と3枚役は中・右から始める4択。ナビを外した場合はレバー時に決めた1/8の1枚、それ以外は0。左始動の右上がり黄7は左からなら15枚、ミス時は1枚とする試遊モデルです。
- 目押しを要求せず、特殊1枚Cと共通赤7は自動補助。実機のリール位置・滑り・通常逆押しペナルティは未再現です。通常表は左始動を前提とした出現モデルで、変則押しによる全フラグの変換はしません。
- SGGの逆押し赤7と逆押しフェイクには同じ右→中→左のナビを表示。当たりかどうかをナビだけで判別できません。共通赤7にも同じナビを出します。逆押し赤7で右から始めなかった場合は青7リプレイへ変わり、GGを追加しない試遊仕様です（正確な実機ペナルティの再現ではありません）。
- 正しい赤7成立でGG1セットとSGG残り16Gへの巻き戻し。共通赤7は目押し補助のため停止順にかかわらず成立します。最後のSTOPまでは払い・上乗せを確定しません。
- G-STOPの上部抽選は左→中→右、HOLDは中のみ。下部の押し順は自動補助する簡略化です。HOLD中のGOD/共通赤7は特別役を優先し、3STOPでその絵柄を表示します。
- 押し順を間違えた時点以降の帯は外れた形にし、既に止まった帯は変えません。上部/下部の見た目から実機の全停止形を推定しないでください。決済表示ではリプレイ返却と払い出しを分けます。
