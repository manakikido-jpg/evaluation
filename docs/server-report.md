# サーバーのようすの集計（読むだけ）

サーバーの今のようすを、いろいろな数字で見るための集計です。**DB・Discord・設定は何も変えません。** 名前・ID・書き込みの中身は出さず、人数・合計・中央値・分布だけを出します（チャンネルの名前は出します）。

社務所Web の「推移」→「📋 レポート」（`/stats/report`）でも、同じ数字をグラフと表で見られます（VPS に入らなくてよい）。

## 手順（VPS で）

1. VPS に入り、BOT のフォルダ（ふだん `docker compose` を打つ場所）に移る。
2. 集計する（はじめは直近 30 日・週ごとは 8 週）:

   ```sh
   docker compose exec bot node dist/scripts/server-report.js
   ```

   期間を変えるときは `--days 7`（365 まで）、週ごとの週の数は `--weeks 12`（26 まで）。ファイルにしたいときは、うしろに ` > server-report.txt`。
3. 出た文をそのまま、チャットに貼ってください。

## 出るもの

1. **人数**: 在籍（男女）・年齢区分・役職ごと・入った人・抜けた人（前の期間とくらべる）・入った人のうち今もいる人。
2. **浮上**: 期間に浮上した人（発言・通話・男女）・1 日あたりの平均・いちばん多い日・浮上した日数の分布・曜日ごとの平均。
3. **時間帯**: 0〜23 時の、1 日あたり平均の浮上・通話・発言の人数と、いちばん多い時間・静かな時間（`activity_hourly`）。
4. **通話**: 合計時間・男女・1 人あたりの分布・縁側・よく使われた通話 10。
5. **発言**: 合計・男女・1 人あたりの分布・よく書かれたチャンネル 10（書き込みの記録から）。
6. **朱印・ご縁**: 押された数・押した人・押された人・取り消し・特別ご縁・自動で上がった人数。
7. **銭**: 増えた・減った合計、今いる人の残高（合計・中央値・上位 10%）、増えた理由・減った理由の多い順。
8. **カジノ**: ゲームごとの回数・人数・賭けた・戻った・胴元・戻り率。
9. **授与所・物御籤・おみくじ**: 件数・人数・合計・よく買われたもの・おみくじの結果。
10. **案内・招待・キャスト・お問い合わせ**: 件数・完了・受付から完了までの時間・指名の数など。
11. **週ごとの推移**: 週ごとの浮上・発言した人・通話した人・通話と縁側の合計・発言の数・朱印・入った・抜けた。

## 読むときに気をつけること

- 浮上 = その日に 1 回でも発言したか、通話（AFK をのぞく）にいた人。BOT は数えない。週ごとの推移は、退出した人もふくむ。
- 男女は 男性・女性 のロールで分ける（ロールがなければ「不明」）。
- 時間帯は、記録を始めた日より前の分はない。書き込みの記録は 90 日分だけ。
