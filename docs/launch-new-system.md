# 新制度ローンチの手順書（宮司・運営むけ）

新制度（結び・ご縁・絵馬・昇格・特典）を**実際に始める日**の手順です。
いまは全部スイッチの裏で眠っていて、宮司が切り替えるまでメンバーの見え方は変わりません。
設計の全体は [new-system-design.md](new-system-design.md)、機能の説明は [admin.md](admin.md) を見てください。

> **大事**：下の 3（絵馬での昇格を ON）が「新制度を始める瞬間」です。
> ここを押すと昇格のきまりが変わるので、**絵馬が十分たまってから**・**周知と同じ日に**行ってください。

---

## 始める前に（数日〜数週間かけて）

1. **絵馬をためる期間をつくる。** メンバーに「🎐 絵馬を贈れるようになった」ことだけ先に周知ずみ（氏子以上が、いっしょに過ごした相手に贈れる）。
   昇格にはまだ使っていないので、この間にみんなが絵馬を集められます。
2. **たまり具合を確かめる。** 社務所Web →「評価」→「🎐 絵馬での昇格」の中の
   「維持の注意：有効な絵馬が維持の枚数未満の氏子」を見て、**氏子が維持の枚数（既定3枚）を持てているか**を確認します。
   たまっていないのに ON にすると、多くの氏子が「維持不足」のお知らせを受け取ってしまいます。
3. **枚数を決める（必要なら）。** 「🎐 絵馬の枚数」で、参拝者→氏子（既定5）・維持（既定3）・氏子→世話役（既定3）・世話役→総代（既定3）を調整できます。
   たたき台のままでもかまいません。**0 は不可**（維持だけ 0＝維持警告なし にできます）。

## 通し稽古（リハーサル）
当日の手順（③→④→⑤→元に戻す）は、テストで丸ごと通し稽古しています。ローンチの前にもう一度確かめたいときは、開発の端末で：
```
npx vitest run test/app.test.ts -t "通し稽古"
```
確かめていること：③で絵馬がたまった人がいっぺんに昇格し、通知はまとめて1回／③と④のすき間に旧ご縁で特典を払わない／④でご縁0・呼び名が結び・コマンドの日本語名を登録し直し・標準の掲示と用語集が入れかわり、手を入れた掲示は残して #記録 に名前／結びは重み1・1回きり／新しいご縁で節目特典／プロフィールの言葉／⑤でカジノ・宿は氏子から／④を元に戻すと言葉・掲示・用語集・コマンド名・旧ご縁が戻る。

## ローンチ当日（この順番で）

1. **【任意】枚数の最終確認** … 社務所Web →「評価」→「🎐 絵馬の枚数」。
2. **③ 絵馬での昇格を ON** … 「🎐 絵馬での昇格」→「切り替えてよい」にチェック→切り替え。
   - これ以降、昇格は**全部「絵馬」**で決まります（ご縁・縁側時間は使いません）。参拝者→氏子は氏子の票、氏子→世話役は世話役の票、世話役→総代は総代の票。
   - 自動降格はしません。今いる人は据え置きです。
   - 絵馬がたまっていた人が**いっぺんに昇格**します。4人以上が同時に上がるときは、#慶事 の1人ずつの発表には役職の通知を付けず、最後に「◯名が昇格」を1回だけ通知します（通知の連打を防ぐ）。
   - いっしょに自動で切り替わる表示：プロフィールの「次の段」（絵馬の枚数で案内）／ `/浮上` の「氏子の条件の縁側時間」は出なくなり「絵馬で決まる」と案内／#お参り判定 のカードは「氏子の票 ◯/必要数 枚」を目安に表示。
3. **④ ご縁のリセット** … 「🔄 ご縁のリセット」→「リセット」と入力＋チェック→実行。
   - 全員のご縁（結び＝朱印）と ✨ 特別ご縁を 0 に戻し、みんな同じところから結び直せます。**役職は変えません。**
   - ③を ON にした**あと**でないと押せません。押した直後なら「元に戻す」で戻せます。
   - **ここで「新制度のご縁の時代」が始まります。** 次のものは④を押した瞬間から切り替わります（③だけでは動きません）：
     - 結びの重みが **参拝者1・氏子1・世話役2（総代以上は1）** になり、**同じ相手には1回きり**（昇格しても押し直しで足さない）。
     - ⑦ **ご縁の節目特典**と、⑥ **招待の結び補填（ご縁）**が動き出す。
     - ③と④のあいだに旧制度のご縁で特典が一斉に払われる事故は、仕組みで防いでいます（④の前は払わない）。
     - **呼び名が「御朱印」→「結び」に自動で変わります（④c）**。1分ほどで BOT が切り替えます：
       - Discord の言葉（結ぶボタン・返事・プロフィールの欄・通話の一覧・#絵馬 の「🧵 結ぶ」ボタン・入ったときのDM・/はじめて・通帳・ショップの説明）。
       - コマンドの日本語の名前（`/御朱印帳` → `/ご縁帳`、`/パネル 朱印` → `結ぶ`）。Discord に登録し直します（振り分けは英語名なので、古いボタンもそのまま動きます）。
       - **掲示と用語集**：標準の文面のまま（運営が手を入れていない）ものは、結びの文面に入れかえて投稿し直します。**手を入れてある掲示は勝手に変えず**、#記録 に「手で直してほしい掲示」の名前を出します（その分だけ、下の「掲示の書き換え文」を使って直してください）。
4. **⑤ 特典のゲートを ON** … 「🎁 特典のゲート：カジノ・宿を氏子から」→チェック→切り替え。
   - カジノ・宿が氏子以上だけになります（参拝者には「氏子になると入れます」と案内）。
5. **【任意】⑦ 節目特典の確認** … 「🎁 ご縁の節目特典（称号・ごほうび・解放）」。称号や**解放**（限定チャンネルを開くロール）を付けるなら、ロールIDを入れて保存（はじめは銭のみ）。
6. **#記録 を見る** … ④のあと1分ほどで「🧵 呼び名を『結び』に切り替えました（掲示 ◯ 件・用語 ◯ 件…）」が出ます。「手で直してほしい掲示」が書いてあれば、その掲示だけ直します。
7. **周知する** … 下の「周知文」を #お知らせ 等に投稿（画像は周知担当に依頼）。

> 当日のコードの変更はありません（呼び名・掲示・コマンド名は④で自動）。

## うまくいかないとき（戻し方）

- **昇格を元に戻したい** … ③「🎐 絵馬での昇格」を OFF に戻すと、従来（ご縁40＋縁側20時間）に戻ります。
  - ただし④リセットのあとだと、ご縁はリセット後の新しい数（少ない）なので、従来の条件にはなかなか届きません。**完全に元へ戻すなら④も「元に戻す」**（押した直後だけ）。元に戻すと新制度のご縁の時代も終わり（結びの重みは旧御朱印に戻る・節目特典は止まる・呼び名・掲示・用語集・コマンド名も1分ほどで「御朱印」に戻る）。
- **リセットを取り消したい** … ④の「直前のリセットを元に戻す」（押した直後だけ）。
- **カジノ・宿を元に戻したい** … ⑤「🎁 特典のゲート」を OFF に戻すと、参拝者から入れます。
- どれも**役職（階級）そのものは勝手に変わりません**。自動降格はしません。
- **荒らしの一言・不正な絵馬（なれあい・頼まれて贈ったもの）** … 社務所Web のメンバーのページ「🎐 絵馬の取り消し（宮司だけ）」で1枚ずつ取り消せます。贈った人の名前は出ません。取り消すと票の数からも外れます（#記録 に残ります）。
- **維持不足のお知らせ** … ③ON のあと、氏子の票が維持の枚数を割った氏子へ本人にDMが届きます（1回だけ・据え置きの氏子には届かない）。多すぎるときは「🎐 絵馬の枚数」の維持を下げる（0で止める）。

## 周知文（たたき台・メンバーむけ）

> 投稿する前に、文面と画像を周知担当と最終確認してください。日付・固有名は入れていません。

**タイトル**：🌸 咲楽ノ宮が新しくなりました

**本文**：
```
今日から、咲楽ノ宮の「つながり」の仕組みが新しくなりました。

🧵 結び … 出会った方へ「はじめまして」の気持ちで贈るあいさつです（御朱印帳から）。結ぶと「ご縁」がたまります。
💞 ご縁 … 結びでたまる数です。節目に届くと、ちょっとしたごほうびがあります。コレクションとして、出会った方をどれだけ結べたかも見られます。
🎐 絵馬 … 「この人いいな」と思った相手へ贈る“評価の票”です。氏子以上の方が、いっしょに過ごした相手に匿名の一言をそえて贈れます。
　→ これからの昇格は、この「絵馬」で決まります（参拝者→氏子、氏子→世話役、世話役→総代）。ご縁や滞在時間ではなく、みんなの「いいね」で上がっていきます。

🎁 カジノ・宿は氏子からになりました。参拝者のあいだは、まずは通話で仲良くなって、絵馬を集めて氏子を目指してください。

これまでのご縁は、みんな同じところから始められるよう、いったん 0 にそろえました。
役職（階級）はそのままです。急に下がることはありません。どうぞ安心して、ゆっくり結んでいってください。
```

**画像の指示（周知担当むけ）**：
- 絵馬（木のふだ）・糸（結び）・桜のやわらかいイメージ。和の落ち着いた桜色。
- 「結び → ご縁 → 絵馬」の流れがなんとなく伝わると良い。文字は入れない（または最小限）。
- 実在メンバーの名前・アイコンは使わない。

## 掲示の書き換え文（たたき台・しきたりの段の置きかえ用）

> 標準の文面のままの掲示は④で自動で入れかわります。**運営が手を入れてある掲示**（#記録 に名前が出たもの）だけ、社務所Web の「掲示」で、しきたりの「朱印を押す」「ご縁と役職」「お参り期間」の段をこれに置きかえます。
> `{…}` は差し込み（枚数は「🎐 絵馬の枚数」に合わせて自動で入ります）。ボタンの名前は ④c で変えた名前に合わせてください。

```
## 結び（はじめましてのあいさつ）
相手の名前を右クリック（スマホは長押し）→「アプリ」→ **プロフィール** → 結ぶボタン
- 同じ人には **1 回だけ**。結ぶと相手の **ご縁** が増えます（間違えたら、押したあとに出るボタンで取り消せます）
- 自分と BOT には結べません
- ご縁は役職には使いません。ご縁が節目に届くと、ごほうびがあります。出会った方をどれだけ結べたかも、プロフィールで見られます

## 絵馬と役職
役職は **絵馬**（評価の票）で上がります（上がると {#慶事} で発表されます）。
氏子以上の方が、いっしょに過ごした相手に、匿名の一言をそえて絵馬を贈れます。
{役職一覧（絵馬）}
-# 一度上がった役職は、自動では下がりません

## お参り期間
入ってから **{お参り期間} 日** は「お参り期間」です。この間に 🍃氏子（絵馬 {氏子の絵馬} 枚）を目指しましょう。
届かなかったときは {お参り延長} 日延長され、それでも届かなければ神職が今後を決めます（退出になることもあります）。
```

## 決めておいたこと（あとから変えられます）
- **呼び名（決定）** … 朱印を押す→**結ぶ**／御朱印帳→**ご縁帳**（`/ご縁帳`。右クリックのメニューは「プロフィール」）／朱印をくれた人→**結んでくれた人**／用語集の格→**絵馬**。
- **結びの重み（決定）** … 参拝者1・氏子1・世話役2・総代・神職・宮司は1。
- **⑦の「③解放」** … 仕組みはできています。「🎁 ご縁の節目特典」で、節目に**限定チャンネルを見られるロール**を付けると、そのチャンネルが開きます（例：ご縁200で『縁結びの間』）。何を開くか（どのチャンネルを作るか）は、宮司がサーバーで用意して設定するだけで、コードの変更はいりません。
- **特別ご縁（運営が手で振るご縁・決定）** … **残します**（今までどおり、社務所Web のメンバーのページから宮司が振れます）。④のリセットでは、それまでの特別ご縁も 0 に戻ります。やめたくなったら、振らなければよいだけです。
